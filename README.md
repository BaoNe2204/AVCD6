# AVCD6 - Ứng Dụng Web Ôn Tập Tiếng Anh Chuẩn 5 Đề Thi

Trang web ôn luyện trắc nghiệm tiếng Anh AVCD6 giúp sinh viên ôn tập và qua môn với tỷ lệ đỗ cao nhất.

## 🚀 Các Tính Năng Nổi Bật

1. **Chuẩn 5 Đề Ôn Tập (250 câu trắc nghiệm)**:
   - Đề 1, Đề 2, Đề 3, Đề 4, Đề 5 (mỗi đề đúng 50 câu).
   - Chia 2 chế độ luyện:
     - **Luyện theo từng đề riêng biệt** (Đề 1 đến Đề 5).
     - **Chuyên đề tổng hợp cả 5 bài**: Tổng Ngữ pháp (50 câu), Tổng Từ vựng (50 câu), Tổng Viết lại câu (50 câu), Tổng Điền từ (50 câu), Tổng Đọc hiểu (50 câu).

2. **Chọn là biết ngay TẠI SAO SAI & TẠI SAO ĐÚNG**:
   - Khi chọn sai: Cảnh báo đỏ phân tích trực tiếp lý do phương án vừa chọn bị sai.
   - Chỉ ra đáp án đúng kèm phân tích ngữ pháp, collocations và ngữ cảnh.

3. **Dịch nguyên câu & Tra nghĩa chi tiết**:
   - Dịch trọn vẹn cả câu tiếng Anh sang tiếng Việt.
   - Bảng dịch nghĩa chi tiết 4 phương án A, B, C, D.
   - Thẻ từ vựng trọng tâm trong câu.

4. **⚡ Mẹo Nhận Biết Nhanh 3s Qua Môn**:
   - Dấu hiệu từ khóa (*keywords*) xuất hiện trong câu để chọn nhanh không cần dịch hết cả bài.

5. **Chống học vẹt**:
   - 🔀 Đảo ngẫu nhiên vị trí các lựa chọn A, B, C, D.
   - 🔄 Xáo trộn thứ tự câu hỏi.

6. **Chế độ thi thử (Exam Mode)**:
   - Đồng hồ đếm ngược 60 phút, nộp bài chấm điểm thang 10, phân tích điểm mạnh/yếu.

7. **Bảng Quản Trị ADMIN**:
   - Chỉnh sửa câu hỏi, đáp án, lời giải, thêm/xóa câu hỏi, xuất/nhập file JSON backup.

## 💻 Cách Chạy

Mở trực tiếp file `index.html` trong bất kỳ trình duyệt web nào (Chrome, Edge, Cốc Cốc, Safari) hoặc chạy local server:
```bash
python -m http.server 5500
```
Truy cập: `http://localhost:5500`
